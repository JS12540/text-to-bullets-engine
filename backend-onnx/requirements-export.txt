# "Known issues" section for the full trail of incompatibilities hit getting

# to need to re-pin if any of these move.

# MUST use Python 3.12 (torch==2.2.2 has no 3.13+ wheels) and a separate venv
# from the dequant phase (see requirements-dequant.txt for why).
#
#   uv venv --python 3.12 .venv-export
#   uv pip install --python .venv-export/bin/python -r requirements-export.txt
#   .venv-export/bin/python export_onnx.py
#   .venv-export/bin/python run_onnx.py
