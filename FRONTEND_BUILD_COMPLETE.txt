================================================================================
                        BACKEND INTEGRATION
================================================================================

EXPECTED ENDPOINTS:

GET /health
  Response: {"status": "ok"}
  Purpose: Simple liveness check

GET /ready
  Response: {"ready": true/false, "reason": "..."}
  Purpose: Verify model is loaded

POST /v1/bullets/stream
  Request:  {"text": "..."}
  Response: Server-Sent Events (streaming)
  Chunks:   Plain text or JSON with metrics
  Expected: {"input_tokens": 112, "ttft": 0.68, "total_latency": 1.82, ...}

ERROR RESPONSE (400):
  {
    "detail": {
      "error_code": "TOKEN_LIMIT_EXCEEDED",
      "message": "Input exceeds maximum token count",
      "actual_tokens": 2567,
      "max_allowed_tokens": 2000
    }
  }

METRICS EXPECTED:
  - input_tokens      (total tokens in system + task + user text)
  - output_tokens     (count of generated tokens)
  - prefill_time      (encoder latency in ms)
  - ttft              (time-to-first-token in ms)
  - mean_itl          (mean inter-token latency in ms)
  - total_latency     (complete request duration in ms)
  - reached_eos       (boolean, whether EOS token generated)

Frontend displays "—" for missing metrics. Never manufactures values.

================================================================================
                        KEY IMPLEMENTATION DETAILS
================================================================================

STREAMING LOGIC:
  File: lib/stream.ts
  
  1. Fetch POST /v1/bullets/stream with {"text": "..."}
  2. Get response.body.getReader() for streaming
  3. Decode chunks with TextDecoder
  4. Parse SSE format (data: "...")
  5. Call onChunk(text) for each chunk
  6. Handle JSON metrics with onMetrics(metrics)
  7. AbortController for cancellation
  8. Return { text, metrics } on completion

STATE FLOW:
  File: app/page.tsx
  
  1. User types → setInputText (updates textarea)
  2. Click "Generate" → handleGenerate()
  3. Set status to "connecting"
  4. Call streamBullets() with onChunk, onMetrics callbacks
  5. onChunk appends to outputText, sets status to "streaming"
  6. onMetrics updates metrics, calculates latencies
  7. Loop until EOS or max tokens
  8. Set status to "completed"
  9. Try/finally cleanup on error

COPY TO CLIPBOARD:
  File: components/output-card.tsx
  
  navigator.clipboard.writeText(output)
  Temporary "Copied" state for 2 seconds
  Falls back gracefully if clipboard unavailable

EXAMPLE BUTTON:
  File: app/page.tsx
  
  Pre-defined sample text:
  "Acme reported quarterly revenue of $4.2 billion..."
  Populated on click, no automatic submit

RESPONSIVE LAYOUT:
  File: app/page.tsx (grid logic)
  
  Desktop: grid gap-6 lg:grid-cols-2 (side-by-side)
  Tablet:  grid-cols-1 (default Tailwind stacking)
  Mobile:  single column, full width
