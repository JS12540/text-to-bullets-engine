## KEY ARCHITECTURE

Request Flow:
  1. Validation    → Pydantic, token count check
  2. Prefill       → T5 encoder, save encoder outputs
  3. Decode Loop   → Token generation with KV cache reuse
  4. Stream        → SSE yield chunks
  5. Cleanup       → Release per-request tensors

Model loaded at startup, stays in memory, reused per request.
Per-request KV cache and encoder outputs released after request.

  MODEL_PATH          = ./artifacts/text-to-bullets-int8

  MAX_NEW_TOKENS      = 512

  PORT                = 8000

Load from .env:
  $ cp backend/.env.example backend/.env
  $ (edit backend/.env as needed)
  $ cd backend && uv run python -m src.main
